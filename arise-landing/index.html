DOCUMENTATION

Unlock ARISE's Full Potential

Activate the CLI globally and launch the interactive setup wizard:

dart pub global activate arise && arise create

Only the project name is required. Every module is optional, and your choices are saved to .arise.yaml so later feature generation matches your stack automatically.

Bootstrap a full production stack in one non-interactive command (ideal for scripts & CI):

arise create my_app --arch clean --state riverpod --route go_router --network dio --di get_it --storage shared_preferences --lint very_good_analysis

Need a plain Flutter app without Arise modules? Run arise create --skip my_app.

Generate architecture- and state-aware features inside any existing Arise project:

arise gen feature auth -t full

Templates: minimal (empty layers), standard (entities, repos, pages & state wiring), full (models, datasources, use cases, widgets & unit tests).

Extend your project anytime or verify environment health:

arise add dio && arise info && arise doctor

arise add installs built-in Arise modules (updating .arise.yaml) or any pub.dev package (arise add -d mockito). arise doctor checks Dart, Flutter, and template integrity.
